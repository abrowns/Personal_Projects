Fire Spread Project

Description --> The fire spread project was originally a midterm project for my computer science 2
class. I'd like to show this project off as a great display of JUNIT testing; and this is a good example of my ability to make a full/working project out of just an idea and the directions; and my ability to work with someone else's code. This project was handed out with some of the graphics parts in FireSpread_Program.java already filled out, but all the algorithms that deal with probability and area scanning and everything else was apart of the main project work.

Main File --> The main file to compile and run is "FireSpread_Program.java", and the program will
run the simulation automatically and will technically stop when the window is closed.
