Spelling Bee Project

Description --> The spelling bee project was originally a project for my computer science 2
class, and I'd like to show it off as a good example of java knowledge, and my
ability to make a full/working project from just an idea and the directions. This project
was originally handed out with most of the graphics parts in SpellingBeeGraphics.java and 
SpellingBeeEventListener.java already filled out, so that the algorithms of word searching
and string manipulation were the main project work.

Main File --> The main file to compile and run is "SB_Program.java", and you will be met with a
blank skeleton of the full game.

Setup --> To start the game, you need to type 7 distinct letters into the "Puzzle"
text box, no repeating letters. The first letter typed into the puzzle text box
will be the letter that appears in the middle of the beehive, and is a mandatory
letter in every word to be guessed during the game.

Gameplay --> To play the game, you can type any word with 4 or more letters into the "Guess Word"
text box, that MUST have the mandatory letter, and points will be earned based on the length of the word. 
Words that use every letter in the beehive are called "Panagrams", and earn extra points.

Buttons --> You can see every possible answer with the "Solve" button, and clear the screen
with the "Clear Screen" button. The "Shuffle" button will shuffle the letters around
in the beehive, which has no effect on the words that can be answered, but may be useful
for players that want a different visual.
